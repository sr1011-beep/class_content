(1) extends Object
    ex: class A { } -> class A extends Object { }
    
(2) default Constructor 는 생략이 가능하다. 조건 생성자를 하나도 안만들어 주면
    => 아무런 파라미터를 받지 않는 생성자는 default Constructor


2. class는 무엇을 가지고 있는가?
(1) 클래스의 구성 요소 3가지
- 메소드 (Method)
- 멤버 변수 (member variable): 변수 종류 2가지 => 멤버 변수, 지역 변수
=> 멤버 변수는 클래스 전체에서 사용 가능한 변수를 의미하며 클래스 선언 후 바로 내부에 정의
-생성자 ( Constructor )

* static : static 선언해준 변수나 메소드는 프로그램이 시작될 때 제일 처음 지가 알아서 메모리에 단 한번만 올라감. 그리고 프로그램이 끝날 때 까지 메모리에 존재.

3. 생성자 (Constructor)
- 생성자를 사용하는 가장 큰 목적은 멤버변수 초기화!!
- 생성자 오버로딩(overloading)이 가능
