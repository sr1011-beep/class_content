1. 추상화 메소드(abstract method) : 기능이 구현되어 있지 않은 메소드
- 문법적으로 기능 구현부에 해당되는 "{}"이 존재하지 않아야 함
- 메소드 끝부분에 " ; " 선언
- 메소드 선언 앞부분에 "abstract"


2. 추상화 클래스(abstract class) : 추상화 메소드를 한개 이상가지는 클래스
- 문법적으로 클래스 선언부 맨 앞에 "abstract"
- 객체화가 불가능

3. 인터페이스(interface) : class가 아닌 interface가 따로 존재
- 문법적으로 interface라고 선언하고 내부에 추상화 메소드와 상수만 가질 수 있음 
- 객체화가 불가능
- 인터페이스는 어쨌든 클래스가 아니므로 "extends" 상속을 사용할 수 없음.
 대신 "implements" 문법을 사용해서 하위 클래스에서 구현


* 메소드 오버라이딩(method overriding)
- 상위 클래스로부터 물려받은 메소드 기능을 재정의
- 문법적으로는 메소드 정의부는 그대로 두고 기능만 변경
(단, 접근제한자는 상위보다 넓은 범위로 변경 가능)
