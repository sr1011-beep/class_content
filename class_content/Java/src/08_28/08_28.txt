1. 자바 기본자료형
- 큰 분류 4가지
 (1) 정수형 : byte - short - int -long
    => 암묵적인 default type은 int type
 (2) 실수형 : float - double
    => 명시적으로 default type은 double
 (3) 문자형 : char
    char c = 'A';
    char c = 65;
 (4) boolean형 : boolean
    true or false 만 저장 가능


2. 배열 - 같은 타입의 값을 여러개 저장할 수 있는 공간
-배열 사용을 위한 문법 3가지
 (1) int[] x = {10, 20, 30};
 (2) int[] x = new int[3];
 x[0] = 10; x[1] = 20; x[2] = 30;
 (3) int[] x = new int[]{10, 20, 30};
 - 다차열 배열 사용시 동적할당이 가능
 int[][] x = new int[3][]; -> 각 행의 열 부분을 따로 지정가능

 3. 자바에서 "=" 의 의미
 -기본 자료형만 빼고 나머지 모조리 주소값이 넘어감
 -기본 자료형은 값이 넘어간다
 int x = 10;    // 기본자료형 이라서 값이 넘어감

 int y = x;
 x = 100;
 y => 10

 int[] x = {10, 20, 30}; // 기본자료형이 아니라서 메모리 주소값이 넘어감
 int[] y = x;
 x[0] = 100;
 y[0] => 100
