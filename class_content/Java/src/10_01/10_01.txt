1. 자바 3대 생략 요소
class A{}  -> 이코드에 생략된 문법이 3가지다?
(1) extends Object
(2) default constructor -> 생성자를 아무것도 만들지 않을경우에만
(3) super();  -> 모든 생성자 첫번째 라인에 생략됨
    super( ); -> 상위 클래스 생성자 호출

2. 상속
- 자바에서 상속은 대상이 클래스 
- 문법적으로 상속을 받기 위해 "extends" 키워드를 사용
ex: class A extends B {} -> A클래스는  B 클래스를 상속 받는다.
- 자바에서 상속 단일 상속만 지원!!!!
- 그렇다면 상속의 대상이 클래스에 있는 멤버변수, 메소드, 생성자를 다 상속받는다 라고 보면되나??  멤버변수, 메소드만 상속되고 생성자는 상속이 안됨!!!!

3. 생성자
- 클래스 구성요소 중 하나
- 문법적으로 메소드와 유사하나 리턴형이 없고 이름이 클래스명과 같아야함
- 하나의 클래스 안에는 여러개의 생성자가 존재할 수 있음. 
 => 생성자 오버로딩이 가능하다
- 생성자는 클래스가 객체화 될때 단 한번 호출
  ex: new A();  -> A() 생성자 호출
- 디펄트 생성자는 생략이 가능 -> 단 생성자를 하나도 안만들어줄경우에만 생략 가능
- 생성자를 사용하는 가장 큰 목적은 멤버변수 초기화
