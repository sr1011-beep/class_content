(2)chatracter stream 계열 : 문자 단위로 데이터 읽기/쓰기

1. 자바로 네트워크상에 데이터 입출력
- TCP / IP 기반의 네트워크 통신
- Socket : 종이컵
  TCP / IP 기반의 데이터 송수신을 위해 서버랑 클라이언트 양쪽에 종이컵이 필요

- Server 에서 종이컵 만들기
- Client 에서 종이컵 만들기

* Server는 client의 접속을 기다리는 곳
  Client는 접속을 하는 쪽, 일반적으로 서버는 1개이고 여기에 데이터를 쌓아두고 클라이언트들이 접속해서 데이터를 받아감

* 문자 처리 유의사항(문자처리를 위한 국제표준 - ChatracterSet)
- utf-8 : 문자 처리를 위해 3byte 사용, 전세계 대부분언어 커버
- euc-kr : 문자 처리를 위해 2byte 사용, 아스키코드(영문) + 한글

2. Inner class(내부 클래스)
- 클래스 안에 클래스 정의 가능
- 내부 클래스에서는 외부 클래스 멤버변수 접근이 가능


. 예외 상황 처리 -> try - catch

* 생성자 첫번째 라인 동시사용은 불가 : super(), this() 하나만 사용 가능
super() -> 생성자 상속 단점 보완
