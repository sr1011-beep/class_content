# 초보자를 위한 코드 읽기 가이드

## 1. 세 파일의 역할 먼저 구분

- **HTML (`index.html`)**: 화면에 **무엇이 있고, 어떤 순서로 보일지** 정함.
- **CSS (`css/*.css`)**: 화면 요소의 **색, 크기, 간격, 위치**를 정함.
- **JavaScript (`js/*.js`)**: **버튼 클릭, 데이터 저장, 댓글 갱신**처럼 움직이는 기능을 정함.

## 2. HTML에서 자주 보는 문법

```html
<div class="about-featured">
    <section id="about" class="profile-panel content">
        <h2>About Me</h2>
    </section>
</div>
```

- `<div>`: 요소들을 묶는 상자.
- `<section>`: 의미 있는 내용 한 구역.
- `<h2>`: 제목.
- `class="profile-panel content"`: 두 클래스를 가진다는 뜻. CSS는 `.profile-panel`, `.content`로 선택.
- `id="about"`: 이 요소만의 식별자. JS에서는 `getElementById('about')`으로 찾음. 메뉴에서 `href="#about"`을 누르면 이 위치로 스크롤.

## 3. CSS에서 자주 보는 문법

```css
.about-featured { margin: 24px 0 28px; }
#profileImage { width: 100%; }
body.dark { --surface: #1e2023; }
```

- `.about-featured`: class가 `about-featured`인 요소.
- `#profileImage`: id가 `profileImage`인 요소.
- `margin`: 상자 **바깥쪽 여백**. `24px 0 28px`은 위24, 좌우0, 아래28.
- `padding`: 상자 **안쪽 여백**.
- `display: flex`: 자식 요소를 가로/세로로 유연하게 배치.
- `display: grid`: 자식 요소를 열과 행의 격자에 배치.
- `border-radius`: 모서리 둥글게.
- `var(--surface)`: 미리 정의한 CSS 색상 변수 사용.
- `@media (max-width: 580px)`: 화면이 580px 이하일 때 적용하는 모바일 전용 스타일.

## 4. JavaScript의 핵심 흐름

### Todo

1. `loadTodos()` : localStorage에 있는 예전 할 일 목록을 불러옴.
2. `addTodo()` : 입력한 텍스트로 새 할 일 객체를 만들어 `todos.push(...)`.
3. `saveTodos()` : `JSON.stringify(todos)` 후 `localStorage.setItem(...)`으로 저장.
4. `renderTodos()` : `todos.forEach(...)`로 작업 카드를 만들어 세 열에 나누어 표시.
5. `changeTodoStatus()` : 완료/진행 중 등 상태 변경 → 저장 → 다시 출력.

### 댓글

1. `start()` : Firebase 익명 인증 → 댓글 실시간 읽기 시작.
2. `addComment()` : 입력값을 Firestore에 `addDoc`으로 저장.
3. `onSnapshot()` : 댓글이 변경되면 `renderComments()` 자동 호출.
4. `renderComments()` : 댓글을 각각 `<li>`로 만들어 화면에 추가.

## 5. 주석은 실행되지 않는 설명

- HTML: `<!-- 여기에 설명 -->`
- CSS와 JavaScript: `/* 긴 설명 */`
- JavaScript 한 줄: `// 한 줄 설명`

주석은 설명이므로 삭제해도 기능이 같지만, 공부하는 동안 남겨두면 좋아요.

## 6. About Me 위치는 어디에서 바꿨을까?

`index.html`의 `<main class="main-content">` 안에서 다음 순서입니다.

1. `section.overview`: Studio Space 제목
2. `div.about-featured`: **About Me** (맨 위로 이동한 구간)
3. `section.stats-grid`: 작업 현황 숫자
4. `section.tasks-section`: 할 일 칸반 보드
5. `div#projects`, `div.info-grid`: 프로젝트·공부·GitHub
6. `section#guestbook`: 댓글

이 순서를 바꾸고 싶으면 해당 HTML 덩어리를 옮기면 됩니다. 단, **`id`를 변경하면 JS 기능이 작동하지 않을 수 있으니** 주의하세요.
