1. 예외 처리(Exception Handling)
- runtime시에 발생하는 예외/오류 상황을 처리하기 위한 문법
- 자바에서 예외처리를 위해 try ~ catch() 문법을 제공함


ex: int x = 10; int y = 0;
try {
    int r = x / y; ( 예외가 발생하는 곳 )
    }catch( 무엇을 잡아낼지 ) {
        예외를 잡아냈을때 어떤 대처방안을 실행시킬 것인가
    }

- 자바에서는 일반적으로 발생할 수 있는 여러 예외상황들을 XXXException 이라는 이름의 클래스들로 미리 정의해두고 있음
- 예외처리를 하고 일단 예외발생하면 대처코드를 실행해주고 프로그램이 종료되지 않고 계속 실행됨

- 다중 catch()문 가능.
ex : try (
            ...
            }catch( ) {
            }catch( ) {
            }
)

- try() 구문안에서 특정 코드에서 예외가 발생하면 try{} 구문안의 나머지 코드는 실행되지 않음. 이건 결국 try() 구문안에서 예외가 발생할 수 있는 특정 코드가 문제 없이 실행되었을 때만 나머지 코드가 실행된다라는 암묵적인 if문의 적용된 상태로 볼 수 있다.

- 다중 catch()문 가능, 다중 catch()문을 사용할 경우에는 넓은 범위를 커버하는 예외가 아래쪽으로 가야함(안그럼 컴파일에러남)
- 자바에서 예외처리 최상위 클래스는 Exception class

ex : try {
        int r = x/y;
        System.out.printl("나눗셈 성공"); // 바로 위 산술연산이 성공하면 출력
    }catch()...



- 예외처리가이드
(1) 명시적이 예외처리가 강제되는 코드에 예외처리 코딩
(2) 테스트단계에서 예외가 발생되서 프로그램이 종료되면 그때 처리



* 자바에서 멤버변수는 자동초기화 되지만
지역변수는 자동초기화가 되지 않음. 직접 초기화 해줘야 함
