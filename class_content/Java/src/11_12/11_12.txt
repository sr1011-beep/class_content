1. 계산기 로직 처리
 - 계산기 화면에 입력된 계산식("문자열")을 받아서 처리하기 위한 기능 구현
 -> 문자열 (ex: "2+3-1")을 연산자와 피연산자로 분리
 -> 분리된 피연산자("2","3","1")을 숫자형(자바 기본자료형 중 하나)로 변경
 -> 연산자를 이용해서 순서대로 누적 계산

 *문자열 -> 숫자형 변환
 - int 타입으로 변경 : Integer.parseInt("2")
 - double 타입으로 변경 : Double.parseDouble("2.2")
 - byte 타입으로 변경 : Byte.parseByte("2");

 *숫자형 -> 문자열 변환
 - "" + 숫자형
