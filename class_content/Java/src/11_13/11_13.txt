1. 자바에서 입출력 (I/O)
(1) byte stream 계열 : 1byte 단위로 데이터 읽기/쓰기
- 대표 클래스
InputStream : 1byte 단위로 읽기 -> 추상화 클래스
OutputStream : 1byte 단위로 쓰기 -> 추상화 클래스

-파일에 데이터 입출력
FileInputStream : 1byte 단위로 파일에서 읽기
FileOutputStream: : 1byte 단위로 파일에 쓰기
