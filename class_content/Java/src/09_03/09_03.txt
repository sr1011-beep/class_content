1. 연산자
 - 산술 연산자 : +, -, *, /, ++, --, +=, -=
  x++; => x = x + 1
  x--; => x = x - 1
  x+=10; => x = x + 10;

 - 논리 연산자 : &, &&, |, ||, ==, !=
  == : 같은지 확인
  != : 다른지 확인
  &, && : 조건을 둘 다 만족한다면
  |, || : 하나라도 만족한다면
  * &, && : 두개짜리가 더 똑똑함
    && : 앞에 조건이 만족되지 않는다면 두 번째 조건 확인도 안함
    & : 앞에 조건 만족여부와 상관없이 두 번째 조건 확인하러 감
    || : 앞에 조건 만족하면 두 번째 조건 확인하러 안감
    | : 앞에 조건 만족 여부 상관없이 두 번째 조건 확인하러 감

2. 제어문 - if, switch - case
  if ( 조건식 ) { 
    만족할때 수행구문
  } else {
        조건 충족하지 않을때 수행구문
  }

  // if ( 조건식 ) {
    ..
  } else if ( 조건식 ) {}... 가능

3. 반복문

* 자바 변수명, 메소드명, 클래스명 등등을 명명할 때 관례
- 클래스명의 첫 문자는 대문자 사용
- 변수명, 메소드명의 첫 문자는 소문자 사용
