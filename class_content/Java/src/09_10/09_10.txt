1. 메소드 ->(중구난방으로 반복되는 코드의 제거를 위해?)
(1) 메소드 정의를 위한 기본 문법
접근제한자 리턴형 메소드이름 ( 파라미터 ) {
    호출시 수행할 코드;
}

* 접근제한자 : 누가 쓸 수 있는가?
public - protected - default - private
public  : 누구나 쓸 수 있다
private : 나만 쓸 수 있다 (나?는 누구? -> class, 현재 클래스만 사용 가능)

* 리턴형 : 메소드 호출 결과로 뭘 받느냐?
void : 리턴 값이 없다. 그냥 메소드 내 코드 실행하고 끝
기본자료형 or 객체형

*메소드이름 : 메소드 이름, 관례적으로 메소드 이름 첫 문자는 소문자로 사용

*파라미터 : 메소드 호출 할 때 넘겨주는 값들 지정

ex ) public 라면 라면끓여줘 ( int money ) {
        //....
        return new 라면();
}

2. 메소드 오버로딩 (Method Overloading)
-하나의 클래스 안에 동일한 이름의 메소드 정의가 가능
-그럼 나중에 호출할 때 구분 어떻게 함
 => 구분을 위해 메소드 이름은 동일하지만 파라미터 종류나 개수가 달라야함
