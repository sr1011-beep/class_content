* 클래스? 오브젝트?

* PC 구성요소
CPU > MEMORY > BOARD > SSD
폰노이만 구조상에서 CPU는 SSD(or HDD)에 직접 접근이 불가능

성능이 가장 좋은 CPU가 성능 가장 좋지 않은 SSD에 접근해서 프로그램을
실행시키게 되면 결국 성능이 하향평준화가 됨
따라서 컴퓨터 구조상 CPU는 SSD에 접근 불가능하도록 구성되어 있음
그러면 실제로 프로그램을 실행 시키면 SSD에 있는 코드가 그나마 성능이 빠른 메모리로 올라가고 그걸 CPU가 실행시키는 구조를 가짐
근데 100기가 정도의 용량의 프로그램을 실행시켰을 때 몽땅 메모리에 다 올려두는건 비효율적. 지금 당장 사용할 코드만 메모리에 올려서 쓰면 되지 않나 ? 그래서 자바에서는 개발자인 우리가 CPU에게 실행시킬 코드를 메모리에 올릴 수 있도록 문법적으로 기능을 제공.
자바에서는 특정 코드를 실행하기 위해 메모리에 먼저 올려주어야 하며 코드를 메모리에 올릴 때 사용하는 최소 단위를 클래스로 둠
이때 사용하는 문법이 new
예를 들어
class Test { ... } -> 이런 클래스가 있다면
new Test(); -> Test 클래스를 메모리에 올려라
