1. 자바는 객체 할당(new XXX)은 문법적으로 지원하지만 더 이상 사용하지 않는 객체 제거 문법은 지원하지 않는다. 대신 더 이상 사용하지 않는 자원은 GC(Garbage Collector)에 의해서 정리된다.


자바에서 자원할당 : new Test();
자바에서 자원해제 : 자원 해제 문법 x, 대신 GC(Garbage Collector)가 해줌

2. 자바 I/O
- chatracter stream 계열 : 문자 단위로 데이터 읽기/쓰기
대표 클래스
Reader : 문자 단위로 읽기, 추상화 클래스
Writer : 문자 단위로 쓰기, 추상화 클래스

파일에서 문자 단위로 데이터 읽고 쓰기
FileReader : 파일에서 문자 단위로 데이터 읽기
FileWriter : 파일에서 문자 단위로 데이터 쓰기
